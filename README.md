# Rubén Dorta

Solution Architect in Bogotá, Colombia. For 25 years I've turned telecom operators' business rules into systems that run in production: product catalogs, ordering, charging and billing, integrated end to end. The last ten were at Ericsson, embedded with Claro Colombia.

Today I build AI agents and RAG systems in Python, with the same habit: **the model handles language, the rules that matter live in code, and nothing ships before it passes an evaluation.**

## Projects

- **[sentinel-engine](https://github.com/rdorta27/sentinel-engine)** — Customer-service agent for bank transaction disputes, in Spanish and Portuguese. The LLM only labels intent; policy, personal-data masking, confirmation and case creation run in code, with handoff to a human advisor. Built in 10 days as technical lead of a 3-person team for the [Factored AI & Data Hackathon 2026](https://github.com/rdorta27/factored-hackathon-2026-sentinel-engine) ([site](https://rdorta27.github.io/factored-hackathon-2026-sentinel-engine), [video](https://youtu.be/0bjonPPvhEA)); development continues here.
- **[knowman](https://github.com/rdorta27/knowman)** — RAG over Markdown notes that answers citing the exact file and lines, and says so when there is no evidence. Postgres + pgvector, local embeddings with Ollama, an MCP server for agents and a groundedness evaluation.
